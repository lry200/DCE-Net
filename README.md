# DCE-Net

Official implementation of DCE-Net for pansharpening.

## Dataset

The experiments in this work are conducted using [PanCollection](https://github.com/liangjiandeng/PanCollection), a public benchmark for multispectral pansharpening.

Our main experiments use:

- QuickBird (QB)
- GaoFen-2 (GF2)
- WorldView-3 (WV3)

Cross-sensor generalization is evaluated by training on WV3 and directly testing on WorldView-2 (WV2).

Both reduced-resolution (RR) and full-resolution (FR) evaluation protocols are considered. Dataset preparation and preprocessing follow PanCollection.
